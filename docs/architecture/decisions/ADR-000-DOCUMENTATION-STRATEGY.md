# ADR-000 — راهبرد نگهداری مستندات

**وضعیت:** Accepted  
**تاریخ:** 2026-10-08  
**حوزه:** Project Governance / Documentation

## مسئله

برای طراحی Platform Foundation به اسناد آموزشی، تصمیم‌های فنی، گزارش وضعیت و راهنمای استفاده نیاز داریم. در آغاز، فقط مخزن Backend ایجاد شده است و تفکیک فوری اسناد به مخزن سوم هزینه هماهنگی ایجاد می‌کند.

## تصمیم

1. فعلاً پوشه فیزیکی `docs/` در ریشه `platform-foundation-backend` قرار می‌گیرد.
2. زبان اصلی توضیحات فارسی است؛ نام کلاس‌ها، Typeها، APIها، شناسه‌ها، مسیرها و نمونه کد به انگلیسی باقی می‌مانند.
3. سند آموزشی (`concepts`) از تصمیم الزام‌آور (`architecture/decisions`) جداست.
4. تصمیم‌های طراحی پس از بررسی مشترک و تأیید، با وضعیت `Accepted` ثبت می‌شوند.
5. هنگام آغاز توسعه جدی Frontend، برای ایجاد مخازن `platform-foundation-frontend` و مستندات مستقل تصمیم‌گیری و انتقال مستندات برنامه‌ریزی خواهد شد.
6. در زمان انتقال، یک مرجع Canonical و لینک ارجاع از مکان قدیمی حفظ می‌شود؛ کپی‌های موازی به‌عنوان دو Source of Truth مجاز نیستند.

## پیامدها

**مزایا:** شروع سریع، دسترسی کنار سورس، تاریخچه تغییرات و PRهای قابل مرور.  
**هزینه:** اسناد به‌طور موقت با چرخه Git مخزن Backend همراه‌اند.

## خارج از محدوده

این ADR درباره انتخاب معماری CQRS، OpenTelemetry، Cache Provider یا مدل نهایی دسترسی تصمیمی نمی‌گیرد.

## شرط بازبینی

آغاز توسعه عملی Frontend یا افزایش نیاز به PRهای مستقل مستندات.
